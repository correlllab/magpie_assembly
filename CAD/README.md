This directory contains the 3D models for the Magpie Gripper and its interchangeable fingers.

The original parametric modeling for this project was done in Onshape. To ensure compatibility for anyone looking to manufacture or modify the design, the files here have been exported into standard universal formats.

File Format:'.stl': 

Printing Guidelines:
Print using PLA with 30% gyroid infill or 100% infill

Original CAD files are contained within this folder. The CAD assembly is located in this [Onshape](https://cad.onshape.com/documents/ebf3bee4cb16cf8695a8fb0b/w/7cb77bbbbc0cfa118c533903/e/7df3b127506ca0a4fec0e6dc?renderMode=0&uiState=6a8f814e30e68e6c32fd1782) document

Renders of every part, generated from these files, are in
[`../Documentation/renders/`](../Documentation/renders); the print set and the
finger variants are laid out side by side there at a common scale.
