Overview: 
The magpie gripper is a parallel jaw gripper optimized for simp. This repository contains the CAD models, design iterations, and a comprehensive instruction manual for assembling the device.

Design and Experimentation:
A major focus of this project was simplifying the gripper for easier assembly and maintenance while testing interchangeable finger designs to optimize grip on various surfaces.

Finger Designs:
Hard Plastic with Rubber Grip Tape
Silicone
E-flesh

Repository Structure:
CAD: Exported 3D models (STEP/STL) for the gripper mechanism and the interchangeable finger variants.
Documentation: Contains the complete assembly manual with step-to-step instructions and required hardware. Also contains design iterations.
Hardware: Bill of Materials (BOM) detailing fasteners, pins, electronics, and additional components needed for the build

Full instructions for putting the Magpie Gripper together can be found in the 'Documentation' folder. The guide walks through the steps one by one with pictures to assemble a complete gripper.
