This directory contains all the necessary resources to source components and fully assemble the Magpie Gripper.

Assembly Manual: A step-by-step guide detailing the assembly.

BOM (Bill of Materials): A comprehensive list of all required hardware and electronics with price points / grams of printing material needed.

Magpie Design Changes: All design changes between the old gripper and the new gripper including descriptions of changes and current work.

If you are building the Magpie Gripper from scratch, please review the BOM first to ensure you have all hardware on hand before beginning assembly.
