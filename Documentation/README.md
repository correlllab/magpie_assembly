# Documentation

Everything needed to source the parts and put a Magpie gripper together.

| | |
| --- | --- |
| [**assembly.md**](assembly.md) | The step-by-step build, with photographs. Read this on GitHub. |
| [**Magpie Assembly Guide.pdf**](Magpie%20Assembly%20Guide.pdf) | The same guide, formatted to print and take to the bench. |
| [**BOM.md**](BOM.md) | Bill of materials for both versions — hardware, electronics, and grams of filament, with prices. |
| [**MagpieDesignChanges.md**](MagpieDesignChanges.md) | What changed between version 1 and version 2, and the reasoning behind each change. |
| [`figures/`](figures) | The figures used by the assembly guide, cut out of the PDF. |
| [`assembly_photos/`](assembly_photos) | Every photograph taken during the build, full resolution — including the ones the guide did not use. |
| [`design_photos/`](design_photos) | CAD screenshots comparing the old design with the new one. |
| [`renders/`](renders) | Renders of each printed part, generated from the STLs by [`tools/render_stl.py`](../tools/render_stl.py). |
| [`paper/`](paper) | The paper the original hand was published in. |

**If you are building from scratch, read the BOM first** and make sure every item
is on the bench before you start — the guide assumes it.
